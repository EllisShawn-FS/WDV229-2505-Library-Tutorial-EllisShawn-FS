# Framer Motion Tutorial Project

## Overview

This is a simple project to showcase some basic features in the **Framer Motion** library. **Framer Motion** is a powerful React animation library that allows you to enhance your UI with smooth and responsive animations.

## Why I chose Framer Motion

I chose **Framer Motion** because I wanted to give my app more versatility and life. Adding animations always seemed cool to me especially when you can customize them to your liking. 

## Features Shown

- Motion components like ('motion.div')
- Animations
- Basic transitions for opacity and x/y positions
- Hover animation
